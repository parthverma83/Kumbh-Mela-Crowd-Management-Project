Large-scale public gatherings such as Kumbh Mela, concerts, protests, and festivals involve extremely dense crowds where traditional object detection models (e.g., YOLO, SSD) fail due to severe occlusion and tiny visible features.

This project implements a crowd counting and density estimation system using Density Map Regression instead of bounding-box detection. The system accurately estimates crowd count and visualizes high-risk dense regions even in ultra-dense scenarios (1000+ people per frame).
